# カニジャンプ DX（Web 2D アクション版）

手芸ポンポンの「カニ1号」が横断歩道を駆け抜ける、爽快 2D ジャンプアクション Web ゲーム。

## 特徴

- **手触りの良いジャンプ操作**: 長押し可変ジャンプ・2段ジャンプ・急降下（ダイブ）・コヨーテタイム・先行入力に対応
- **横断歩道の障害物とギミック**: 乗用車・スポーツカー・背の高いトラック（2段ジャンプで飛び越え）・カラーコーン・カモメ（くぐり抜け可）に加え、信号機点滅から始まる「ラッシュタイム」を搭載
- **コンボ＆カニ無双 FEVER**: 飛び越え・ニアミス・★スター収集でコンボ倍率アップ＆ゲージ蓄積。満タンで無敵の FEVER モードに突入し、車を吹き飛ばして大得点！
- **2つのゲームモード**: じっくり遊べる「ノーマル（ハート×3）」と、スコア 1.5 倍の一発勝負「チャレンジ」
- **時間帯サイクル**: 昼 → 夕焼け → 星空の夜（街灯・ヘッドライト点灯）→ 朝焼けと背景がリアルタイムに変化
- **WebAudio サウンド**: タイトル曲・プレイ曲（速度連動）・FEVER 曲および効果音を完全内蔵

## 操作方法

| 操作 | スマホ・タブレット | キーボード |
|---|---|---|
| ジャンプ / 2段ジャンプ | 画面タップ / 右下の「ジャンプ」ボタン | `Space` / `↑` / `W` |
| 急降下（空中から素早く着地） | 下スワイプ / 左下の「きゅうこうか」ボタン | `↓` / `S` |
| 一時停止 | 右上の ⏸ ボタン | `P` / `Esc` |
| BGM オン/オフ | 右上の 🎵 ボタン | `M` |

## 開発・ビルド・テスト

```sh
npm install
npm run dev       # 開発サーバー起動（スマホからもアクセス可）
npm test          # ゲームロジック単体テスト
npm run build     # dist/ に本番ビルド出力
npm run preview   # ビルド結果のプレビュー
```
